# Демо за 5 минут

1. После сборки frontend и `uv sync --locked --extra dev --no-editable` запустить `uv run --locked --no-editable money-graph demo --data data --out artifacts/latest`.
2. На стартовом обзоре открыть клиента из топ-листа, показать роль и числовой evidence.
3. Найти его по `gid`, открыть направленное окружение и карточку с вкладами priority.
4. Показать границу `depth=4` или изолированный seed: интерфейс объясняет неполноту
   наблюдения и не называет его terminal автоматически.
5. Скачать три CSV и показать `manifest.json` с хешами входов и временем запуска.
